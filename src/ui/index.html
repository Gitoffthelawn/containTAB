Rule Patterns

example.com — exact domain match

*.example.com — all subdomains

@google — fragment (hostname contains "google")

Containers

Rules assign URLs to shared containers by name.

If the container doesn't exist yet, it's created on first match.

Default Container

When enabled, unmatched URLs get isolated containers (one tab = one container).

Lifetime

Until last tab: container deleted when last tab closes, rule kept for re-creation on next match.

Forever: container persists even with no tabs.

Container Lock

Once a tab enters a container, it stays there. Navigating to a different-rule URL opens a new tab.
